# Japanese curriculum and adaptive teaching

See [workflow](workflow.md) and [storage](storage.md).

## Framework, not a single textbook syllabus

- **JF Standard** supplies proficiency levels and Japanese-language *Can-do* outcomes: what a learner should be able to accomplish. It does **not** prescribe a fixed chapter sequence or complete grammar checklist.
- The learner's **local curriculum map** organizes outcomes, grammar, vocabulary, script, prerequisites, and local chapters/subchapters in the linked folder's `curriculum/map.json`. Chapters are local packaging, not official JF chapters. The map **grows** from goals and evidence; there is no A2 ceiling and no need to pre-map A1–C2 before setup.
- **Marugoto/Irodori** can inform real-world situations and activities; **Genki/Minna no Nihongo/Tobira** and other credible references can inform grammar explanations and prerequisite order. No single book is mandated, and not every source must be read for each lesson. Do not copy copyrighted textbook content. Any test goal is an evidence-based adjustment to coverage and practice, not a hard-coded center of the curriculum.
- The repository may later contain a **read-only starter framework and source policy** (proposed paths: `curriculum/japanese-map.json`, `curriculum/japanese-map.md`, `curriculum/sources.md`). These files **have not been authored or audited** and are not required to be a complete syllabus before setup. User-specific map growth happens only in the linked folder.

Starting official references for framework design—not proof that a particular local prerequisite graph is valid: [JF Standard overview](https://www.jfstandard.jpf.go.jp/summaryen/ja/render.do), [JF course design](https://www.jfstandard.jpf.go.jp/course/ja/render.do), and [Irodori resources](https://www.irodori.jpf.go.jp/en/resources.html). These links are optional references, not a mandatory browsing step for each skill or claim.

## Decisions across sessions

Setup maps a broad initial profile across text-assessable strands before selecting a first target; it does not need to test every possible Japanese skill. It distinguishes recognition from production, samples varied contexts, and leaves listening/speaking unknown when the interface cannot assess them. At each lesson, read the learner's goal, history, map, and evidence; select **one main target** whose prerequisites are supportable, and explain why. Afterward, update the working model of strengths, misconceptions, explanations that helped, repeated errors, and likely next targets. When the existing path is sufficient and the learner is ready for more, **extend the next defensible segment** of the map, including a higher JF level if appropriate. Do not stop because an initial segment ends at A2. Conversely, one lesson or one score does not establish that a learner has officially 'passed A2'; reading, production, and interaction can develop unevenly.

The agent 'learns' by improving its **documented working model and teaching strategy**, not by changing model weights. Stored judgments may be mistaken: distinguish language claims, actually consulted sources, observed learner responses, hypotheses, and unresolved questions. Allow user corrections to revise documented conclusions. If an approach fails, try a different explanation or task instead of repeating the same item.

A goal has a near-term target; its context (travel, work, conversation, etc.) is a **supplement** for vocabulary, examples, and some exercise situations. Ask for details of a job only when relevant and willingly supplied. General Japanese skills and prerequisites remain the main path. Occasionally use another context to test transfer rather than memorization of one scenario.

## Accuracy

External browsing and source checks are optional, not a prerequisite to setup or lessons. For familiar material, the agent may rely on its own Japanese knowledge without claiming external verification. For genuinely doubtful grammar, nuanced grading, or a challenged correction, consult a credible source when available; another model's unsupported confidence is not verification. If uncertainty remains, state it honestly, do not force a verdict, and omit the disputed point as fact from `materials/`. Expand the map conservatively from defensible prerequisites; flexibility does not authorize invented grammar or progression.

Older grammar will naturally reappear when composing new sentences. Use genuinely relevant connections and track recurring difficulties, but **an incidental appearance is not a formal review or progress update**. The workflow has no rating buttons, mandatory spaced-day intervals, or review triggered solely by file age.
